Senior Frontend Architecture Tokens & Theming

Three-Tier Token Architecture (Global, Semantic, Component)

Architectural Impact: Without a 3-tier system, theming, dark mode, and multi-brand support break down into chaotic find-and-replace disasters across thousands of components.
Core Mental Model
Tokens follow a strict unidirectional dependency graph: Component Tokens reference Semantic Tokens, which reference Global Primitive Tokens.
Senior Interview Traps
Exposing global tokens directly to component authors, preventing dark mode or brand rebranding without rewriting component CSS.
