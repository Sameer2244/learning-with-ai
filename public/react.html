Fiber Tree & Linked List Traversal

Production Impact: Understanding Fiber linked lists, double-buffering, and work loop scheduling is critical for optimizing high-frequency UI updates, eliminating dropped frames, and preventing state tearing.
Core Mental Model
In React's Fiber reconciler, every element is converted to a persistent Fiber Node with child, sibling, and return pointers. This converts recursive call stack traversal into an interruptible, heap-allocated linked list traversal that can pause and yield back to the browser main thread.
Senior Interview Traps
Confusing ephemeral React Elements ({ type, props }) with persistent Fiber nodes; assuming fibers use children arrays instead of singly-linked child and sibling pointers.
